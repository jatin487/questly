═════════════════════════════════════════════════════════════════════════════
                       TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

PROBLEM: Still see password field
SOLUTION:
  1. Clear browser cache
  2. Force refresh (Ctrl+Shift+R)
  3. Check file was saved properly
  4. Restart dev server

PROBLEM: Not redirecting to /auth/login automatically
SOLUTION:
  1. Check middleware.ts is updated
  2. Restart dev server
  3. Check browser console for errors
  4. Verify Supabase connection

PROBLEM: Magic link not working
SOLUTION:
  1. Check email (spam folder)
  2. Verify email configured in Supabase
  3. Check SUPABASE_SERVICE_ROLE_KEY is set
  4. Try different email

PROBLEM: Team creation not working after login
SOLUTION:
  1. Make sure logged in (dashboard shows name)
  2. Check Supabase database connection
  3. Verify RLS policies
  4. Check API route: /api/teams
