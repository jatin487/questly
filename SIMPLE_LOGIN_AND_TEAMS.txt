═════════════════════════════════════════════════════════════════════════════
                       JOIN TEAM API ENDPOINT
═════════════════════════════════════════════════════════════════════════════

ENDPOINT: POST /api/teams/join

REQUEST BODY:
  {
    "team_id": "uuid-of-team-to-join"
  }

RESPONSE (Success):
  HTTP 200
  {
    "success": true,
    "message": "Successfully joined [Team Name]",
    "team_id": "uuid"
  }

RESPONSE (Already Member):
  HTTP 400
  {
    "error": "You are already a member of this team"
  }

RESPONSE (Team Not Found):
  HTTP 404
  {
    "error": "Team not found"
  }

RESPONSE (Unauthorized):
  HTTP 401
  {
    "error": "Unauthorized"
  }

HOW IT WORKS:
  1. Check user is authenticated
  2. Verify team exists
  3. Check user isn't already a member
  4. Insert user into team_members table
  5. Return success
  6. Frontend reloads teams data
  7. UI updates to reflect join

═════════════════════════════════════════════════════════════════════════════

WHEN USER JOINS TEAM:

  1. Frontend Click [Join Team]
        ↓
  2. POST /api/teams/join with team_id
        ↓
  3. Backend: Verify user authenticated
        ↓
  4. Backend: Check team exists
        ↓
  5. Backend: Check user not already member
        ↓
  6. Backend: INSERT into team_members
     ├─ user_id: logged in user
     ├─ team_id: selected team
     └─ role: 'member'
        ↓
  7. Return success to frontend
        ↓
  8. Frontend: Reload teams from database
     ├─ User's teams
     └─ All available teams
        ↓
  9. Frontend: Update UI
     ├─ Move team to "Your Teams"
     ├─ Remove from "Available Teams"
     ├─ Update counts
     └─ Show success message
