ISSUE: "Images not uploading - getting error"
SOLUTION:
  1. Check .env.local has actual keys (not "process.env.JWT")
  2. Make sure keys start with "eyJ"
  3. Restart dev server: npm run dev
  4. Check bucket exists and is Public

ISSUE: "404 error when viewing uploaded images"
SOLUTION:
  1. Check bucket privacy is set to Public
  2. Verify bucket name is exactly "mission-submissions"
  3. Check NEXT_PUBLIC_SUPABASE_URL is correct

ISSUE: "Can't find API keys in Supabase"
SOLUTION:
  1. Go to: https://app.supabase.com/projects
  2. Select your project
  3. Click Settings (gear icon)
  4. Click API in menu
  5. Look for "Project API keys" section at bottom

ISSUE: "Dev server not picking up new variables"
SOLUTION:
  1. Stop dev server (Ctrl+C)
  2. Clear terminal
  3. Run: npm run dev
  4. Wait for "✓ Compiled successfully"
