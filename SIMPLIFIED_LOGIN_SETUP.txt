TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ISSUE: Magic link not working
SOLUTION:
  1. Check email (including spam folder)
  2. Make sure Supabase email is configured
  3. Check NEXT_PUBLIC_SUPABASE_URL is correct
  4. Verify email address is lowercase

ISSUE: Getting "Email already registered" but user is new
SOLUTION:
  1. Try with different email
  2. Check if previous signup was completed
  3. Clear browser cookies
  4. Try incognito/private mode

ISSUE: Redirect loop between /auth/login and /dashboard
SOLUTION:
  1. Clear browser cache
  2. Clear cookies
  3. Restart dev server (npm run dev)
  4. Check middleware.ts for errors

ISSUE: Slow login on high traffic
SOLUTION:
  1. Check internet connection
  2. Verify Supabase project is not overloaded
  3. Check email service for delays
  4. Monitor server logs
