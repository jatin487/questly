IMAGE UPLOAD FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. User goes to Mission Detail Page
     ↓
  2. User selects and uploads photo
     ↓
  3. Photo uploaded to Supabase Storage
     Path: mission-submissions/{user_id}/{timestamp}-{filename}
     ↓
  4. Public URL generated
     https://vhnvamifepgdkelgboap.supabase.co/storage/v1/object/public/
     mission-submissions/{user_id}/{timestamp}-{filename}
     ↓
  5. URL saved in Database
     Table: mission_submissions
     Column: photo_url
     ↓
  6. Admin can view in /admin/submissions
  7. On approval, image stays in storage

QUICK MIGRATION TO YOUR PROJECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Get Your API Keys
  ├─ Go to: https://app.supabase.com/projects
  ├─ Select: vhnvamifepgdkelgboap
  ├─ Settings → API
  └─ Copy Anon Key and Service Role Key

Step 2: Create Storage Bucket
  ├─ Storage → Create new bucket
  ├─ Name: mission-submissions
  ├─ Privacy: Public
  └─ Click Create

Step 3: Update Environment Variables
  ├─ NEXT_PUBLIC_SUPABASE_URL=https://vhnvamifepgdkelgboap.supabase.co
  ├─ NEXT_PUBLIC_SUPABASE_ANON_KEY=<your-key>
  ├─ SUPABASE_SERVICE_ROLE_KEY=<your-key>
  └─ Save and restart

Step 4: Test
  ├─ Go to mission
  ├─ Upload photo
  ├─ Check Supabase Storage
  └─ Image should appear ✓

    Solution: Supabase → Settings → API section

  Issue: Environment variables not working
    Solution: Restart dev server or redeploy
